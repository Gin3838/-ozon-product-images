# Ozon product images

Публичное хранилище изображений для загрузки карточек Ozon.

- `rings/` — комплект уплотнительных колец NBR 70, 10 шт.
- `seals/` — армированные манжеты (сальники) TC NBR 70, 1 шт.
- Все товарные изображения: JPEG, 1200×1200 px, без надписей, логотипов и водяных знаков.
- Файлы предназначены для прямой загрузки Ozon по URL `raw.githubusercontent.com`.

Исходный рабочий проект и коммерческие документы в этот репозиторий не загружаются.
